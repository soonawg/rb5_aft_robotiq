# RB UI + 데스크탑 USB 기준 RB5 + AFT200 + Robotiq 설정·운용 매뉴얼

> 기준일: 2026-08-28  
> 장비: RB5-850E, AIDIN AFT200-D80-C, Robotiq 2F-85  
> 프로그램: Rainbow Robotics Windows UI LTS 8.4.4  
> 목적: 처음 장비를 켠 사람도 센서 등록, User Script Command, 그리퍼 설정,
> 물체 파지와 F/T 확인까지 순서대로 진행할 수 있게 한다.

## 1. 이 문서에서 사용하는 연결 구조

```text
Windows PC
├─ Ethernet ─────────── RB5 제어박스(10.0.2.7)
│                       └─ CAN H/L + 5 V/GND ─ AIDIN AFT200-D80-C
└─ USB ─ DTECH USB-RS485 변환기 ─ RS485 ─ Robotiq 2F-85

RB5 제어박스 24 V/GND ────────────────────── Robotiq 전원
```

이 구성에서는 다음 원칙을 지킨다.

- 로봇과 AFT200 설정·확인은 **Windows RB UI**에서 수행한다.
- Robotiq용 DTECH USB는 **Windows 데스크탑 USB 포트**에 직접 연결한다.
- Robotiq은 Windows COM 포트를 사용하는 `rb5_ui.py` 또는 Robotiq RUI로 제어한다.
- RB UI의 `Control Box` 그리퍼 기능은 현재 구성에서 사용하지 않는다.
- PC는 로봇/AFT200과 Ethernet으로, Robotiq과 USB로 각각 통신한다.
- 태블릿 USB와 Robotiq USB-RS485를 혼동하지 않는다.
- Python 통합 UI와 Robotiq RUI는 동시에 실행하지 않고 둘 중 하나만 사용한다.
- Windows PC USB 직결이 이 문서의 기본 Robotiq 연결 방식이다.

## 2. 현재 확인된 설정

| 항목 | 현재 값 |
|---|---|
| 로봇 | `RB5-850E` |
| 제어박스 IP | `10.0.2.7` |
| Windows Ethernet IP | `10.0.2.10/24` |
| Windows RB UI | LTS `8.4.4` |
| 연결 방식 | TCP/IP |
| AFT200 모델 | `AIDIN AFT200-D80-C` |
| 외부 F/T 센서 설정 | `AIDIN AFT200` |
| 외부 F/T 센서 방향 | `Standard` |
| 고해상도 ADC | `Off` |
| 센서 ID 등록 명령 | `AIDIN_ID_SETTING()` |
| F/T 데이터 | Modbus holding register 304~309에서도 확인 가능 |

| 그리퍼 통신 | RS485, `115200`, `8N1`, 기본 slave ID `9` |

## 3. 안전수칙

1. 배선을 만질 때는 제어박스 메인 전원을 완전히 끈다.
2. 비상정지 장치를 연결하고 항상 손이 닿는 위치에 둔다.
3. 최초 움직임은 화면 하단 속도를 `5~10%`로 낮추고 수행한다.
4. 그리퍼 초기화·열기·닫기 전에 손과 물체를 핑거 사이에서 치운다.
5. 로봇 이동 중에는 로봇, 물체, 센서 케이블에 접근하지 않는다.
6. AFT200은 5 V 장치다. AFT200 전원에 24 V를 연결하지 않는다.
7. Robotiq은 제어박스 24 V/GND에서 전원을 공급한다.
8. 센서 케이블이 당겨지거나 플랜지에 눌리면 그 힘도 측정값에 포함된다.
9. 로봇 이동은 RB UI만, 그리퍼 동작은 COM 제어 프로그램 하나만 담당하게 한다.
10. 소프트웨어 버튼은 물리 비상정지를 대체하지 않는다.

## 4. 전원을 켜기 전 배선 확인

### 4.1 AFT200

```text
AFT200 CAN H → 제어박스 CAN H
AFT200 CAN L → 제어박스 CAN L
AFT200 5 V   → 제어박스 5 V
AFT200 GND   → 제어박스 GND
```

- CAN H/L이 서로 뒤바뀌지 않았는지 확인한다.
- AFT200 선이 로봇 움직임 범위에서 팽팽해지지 않게 정리한다.

### 4.2 Robotiq

```text
Robotiq 전원 + → 제어박스 24 V
Robotiq 전원 - → 제어박스 GND
Robotiq 흰색   → DTECH 단자 TX+/A+
Robotiq 초록색 → DTECH 단자 TX-/B-
DTECH USB      → Windows 데스크탑 USB 포트
```

- 사진에서 확인된 흰색/초록색 A/B 위치는 규격과 일치한다.
- DTECH 단자의 `RX+`, `RX-`, `GND`, `+5V`에는 임의로 선을 추가하지 않는다.
- 케이블 속 흰색 섬유나 차폐 포일을 GND에 넣지 않는다.
- Robotiq USB가 빠져 있으면 Windows에 COM 포트가 나타나지 않는다.

## 5. Windows PC와 RB UI 준비

### 5.1 PC Ethernet 설정

제어박스가 `10.0.2.7`일 때 Windows Ethernet IPv4를 다음처럼 설정한다.

```text
IP address: 10.0.2.10
Subnet:     255.255.255.0
Gateway:    비움
DNS:        비움
```

PowerShell 또는 명령 프롬프트에서 확인한다.

```powershell
ping 10.0.2.7
```

응답이 없으면 RB UI 설정을 진행하기 전에 랜선, PC IP, 제어박스 부팅 상태부터 해결한다.

### 5.2 RB UI 버전

- 현재 제어박스에는 Windows용 LTS `8.4.4`를 사용한다.
- 단순히 더 최신이라는 이유로 PRE RELEASE `8.8.2`로 바꾸지 않는다.
- 설치 파일은 [Rainbow Robotics 협동로봇 기술문서](https://rainbowrobotics.github.io/rb_cobot_docs/ko/)
  상단의 `다운로드`에서 받는다.
- 다운로드 폴더에서 `1_Software_Release → LTS 8.4.4 → Windows` 패키지를 선택한다.
- 압축을 원하는 로컬 폴더에 풀고 패키지 안의 `RB_window.exe`를 실행한다. 사용자별
  설치 경로는 매뉴얼의 고정 조건이 아니다.

## 6. 제어박스 부팅·연결·활성화

1. 작업 공간과 배선을 확인한다.
2. 제어박스 전원을 켠다.
3. 완전히 부팅될 때까지 기다린다.
4. Windows RB UI 8.4.4를 실행한다.
5. TCP/IP 연결 화면에서 제어박스 `10.0.2.7`을 선택한다.
6. `Connect`를 누른다.
7. 비상정지와 실제 로봇 상태를 확인한다.
8. `Control/Activate`를 수행한다.
9. 상단에 `Real Robot`, TCP 연결 상태가 표시되는지 확인한다.
10. 화면 하단 속도를 `5~10%`로 낮춘다.

별도의 `State/Connection` 메뉴를 찾을 필요는 없다. TCP 연결 창의 연결·활성화와
메인 화면의 `Real Robot` 상태로 확인하면 된다.

## 7. Tool/TCP와 하중 설정

AFT200, 어댑터, Robotiq이 플랜지에 붙어 있으므로 로봇에 장착 하중을 알려야 한다.

1. 우측 `설정`을 누른다.
2. `Tool/TCP`로 이동한다.
3. `Default Tool` 또는 실제 사용할 Tool을 선택한다.
4. 다음 부품의 합산 질량을 payload로 입력한다. (대략 1.45kg)
   - AFT200
   - 센서/그리퍼 어댑터
   - Robotiq 2F-85
5. 가능하면 실제 무게중심(COM)도 입력한다.
6. 실제 그립 중심까지의 TCP 위치·방향을 실측값으로 등록한다.
7. 저장·적용한다.

주의:

- 물체를 잡기 전 기본 payload에는 물체 무게를 포함하지 않는다.
- 무거운 물체를 잡으면 해당 질량을 더하고, 내려놓은 뒤 원래 값으로 복귀한다.
- 실제보다 큰 값을 안전 여유라고 생각해 임의로 넣지 않는다.
- UI가 재부팅을 요구하지 않으면 Tool/Payload 변경만으로 무조건 재부팅할 필요는 없다.

## 8. AFT200 최초 설정

이 절은 센서가 처음 연결됐거나 설정이 초기화됐을 때 수행한다. 이미 6축 값이 정상적으로
나오고 설정이 보존되어 있다면 매번 반복하지 않는다.

### 8.1 외부 F/T 센서 선택

1. 메인 화면 우측의 `설정`을 누른다.
2. 시스템 설정 화면의 상단 `일반` 탭으로 이동한다.
3. 오른쪽의 `외부 F/T 센서`를 `AIDIN AFT200`으로 선택한다.
4. `외부 F/T 센서 방향`을 현재 설치 기준 `Standard`로 둔다.
5. `고해상도 ADC 모드`는 현재 확인된 설정인 `Off`로 둔다.
6. 설정을 저장·적용한다.

### 8.2 User Script Command로 센서 ID 등록

1. 같은 시스템 설정 화면에서 상단 `User Script Command` 탭으로 이동한다.
2. 비어 있는 슬롯 하나를 고른다. 현재는 0번을 사용했다.
3. Script 칸에 아래 내용을 정확히 입력한다.

```text
AIDIN_ID_SETTING()
```

4. 해당 줄의 `저장`을 누른다.
5. 해당 줄의 `테스트`를 **한 번만** 누른다.
6. 다음 메시지가 나타나는지 확인한다.

```text
[M584] An ID setting command has been sent. Reboot the entire system.
```

이 작업에는 화면 오른쪽 아래의 `설정 가져오기`가 필요하지 않다. 버튼을 눌러도 눈에
보이는 변화가 없을 수 있으며, 그것만으로 센서 연결 실패라고 판단하지 않는다. 필요한
동작은 Script 입력 → 해당 줄 저장 → 해당 줄 테스트 순서다.

### 8.3 M584 이후 전체 재부팅

M584가 나오면 UI만 닫거나 Disconnect만 하지 말고 제어박스 전체를 재부팅한다.

1. 로봇을 정지하고 안전 상태인지 확인한다.
2. RB UI 연결을 종료한다.
3. 제어박스 메인 전원을 끈다.
4. 완전히 꺼진 뒤 다시 전원을 켠다.
5. 부팅 후 RB UI에서 `Connect`한다.
6. 다시 `Control/Activate`한다.

`AIDIN_ID_SETTING()`을 실행할 때마다 재부팅이 필요하다. 센서가 정상 등록된 이후에는
명령을 매일 반복 실행하지 않는다.

### 8.4 센서 값 확인

1. RB UI의 F/T 현재 신호 화면으로 이동한다.
2. Fx, Fy, Fz, Mx, My, Mz가 모두 표시되는지 확인한다.
3. 손으로 그리퍼를 아주 약하게 누르지 말고, 안전하게 외력을 가할 수 있는 조건에서만
   값의 변화 방향을 확인한다.
4. 6축 값이 계속 0이거나 멈춰 있으면 센서 등록/배선 문제로 판단한다.

실장비에서 다음과 같이 0이 아닌 값이 표시되는 것을 이미 확인했다.

```text
Fx 4.12 N, Fy 10.48 N, Fz 54.26 N
Mx -0.45 Nm, My -1.08 Nm, Mz -0.76 Nm
```

이 값은 당시 자세와 부착 하중이 포함된 예시이며 정상 기준값은 아니다.

### 8.5 F/T 영점 조정

1. 그리퍼가 비어 있고 어떤 물체에도 닿지 않게 한다.
2. 실제 측정에 사용할 자세로 로봇을 정지시킨다.
3. 케이블과 로봇 진동이 가라앉을 때까지 기다린다.
4. F/T 화면의 `0` 버튼을 눌러 영점을 맞춘다.
5. 6축 값이 0 근처에서 작은 노이즈만 보이는지 확인한다.

자세를 크게 바꾸면 중력 방향이 달라지므로 무게 측정 직전에 같은 자세에서 다시 영점을
잡는 것이 좋다. `Calibration 활성화` 같은 다른 옵션은 의미를 확인하지 않은 상태에서
임의로 켜지 않는다.

## 9. Robotiq 2F-85 최초 설정

### 9.1 USB와 Windows COM 포트

1. 제어박스 전원을 끈 상태에서 Robotiq 24 V/GND와 RS485 단자를 확인한다.
2. DTECH USB를 **Windows 데스크탑 USB 포트**에 연결한다.
3. 제어박스를 켜 Robotiq에 24 V를 공급한다.
4. Windows `장치 관리자 → 포트(COM 및 LPT)`를 연다.
5. `USB Serial Port (COMx)` 또는 `FT232R USB UART`가 나타나는지 확인한다.
6. 표시된 COM 번호를 기록한다.

현재 USB가 PC에 있으므로 RB UI의 `설정 → Device/Gripper → Control Box` 기능과
`gripper_rtq_2f85_*` User Script Command는 사용하지 않는다. 이 기능들은 USB-RS485가
제어박스 USB에 직접 연결되어 있을 때만 제어박스가 그리퍼와 통신할 수 있다.

### 9.2 데스크탑 그리퍼 프로그램 준비

현재 만든 프로그램을 사용할 경우 `rb5` 폴더를 Windows 로컬 폴더
(예: `C:\rb5_control`)에 복사하고 최초 한 번 실행한다.

```powershell
cd C:\rb5_control
py -m pip install pyserial
```

실행:

```powershell
py rb5_ui.py
```

또는 `run_ui.bat`을 더블클릭한다. Robotiq 공식 RUI를 사용할 수도 있지만 RUI와
`rb5_ui.py`를 동시에 실행하면 안 된다. 하나의 COM 포트는 한 프로그램만 연다.

### 9.3 그리퍼 통신 및 동작 시험

1. 프로그램에서 `새로고침`을 누른다.
2. 장치 관리자에서 확인한 COM 포트를 선택한다.
3. `연결`을 누른다.
4. 응답 가능한 fault 코드가 표시되는지 확인한다.
5. 그리퍼 주변을 완전히 비운다.
6. `Reset + Activate`를 한 번 누른다.
7. 초기화가 끝날 때까지 3~5초 기다린다.
8. 속도 `64/255`, 힘 `32/255` 정도에서 `열기`를 시험한다.
9. 정상적으로 열리면 같은 저속·저힘으로 `닫기`를 시험한다.

COM 포트는 보이지만 `Modbus 응답이 없습니다`가 나오거나 LED가 계속 빨간색이면 명령을
반복하지 말고 14.3절의 순서로 점검한다.

## 10. 매일 시작 순서

최초 설정이 끝난 뒤에는 아래 순서만 따르면 된다.

1. 전원이 꺼진 상태에서 AFT200 CAN/5 V와 Robotiq 24 V/RS485/USB를 확인한다.
2. DTECH USB가 Windows 데스크탑 USB에 꽂혀 있는지 확인한다.
3. 작업 공간과 비상정지를 확인한다.
4. 제어박스 전원을 켠다.
5. Windows RB UI 8.4.4를 실행한다.
6. `10.0.2.7`에 TCP Connect한다.
7. `Control/Activate`한다.
8. 속도를 `5~10%`로 낮춘다.
9. Tool/TCP와 payload가 현재 장착물에 맞는지 확인한다.
10. F/T 6축 값이 갱신되는지 확인한다.
11. 데스크탑 그리퍼 프로그램에서 COM 연결→Reset+Activate→저속 열기/닫기를 확인한다.
12. 빈 그리퍼를 측정 자세에 놓고 F/T `0`을 누른다.
13. 이후 로봇 티칭과 물체 파지를 시작한다.

센서가 이미 정상이라면 `AIDIN_ID_SETTING()`을 다시 실행하지 않는다.

## 11. RB UI와 USB 그리퍼 프로그램으로 물체 잡고 F/T 확인하기

### 11.1 권장 티칭 포인트

다음 자세를 저속으로 하나씩 저장한다.

```text
안전 대기
→ 물체 위 접근
→ 파지 위치
→ 수직 상승
→ 무게 측정 자세
→ 내려놓기
→ 안전 복귀
```

- 장애물이 없는 단순 직선 접근·상승은 MoveL을 사용할 수 있다.
- 관절 뒤집힘이나 자기충돌 가능성이 있으면 MoveJ와 안전 경유점을 사용한다.
- 처음부터 전체 프로그램을 자동 실행하지 말고 각 포인트를 한 단계씩 확인한다.

### 11.2 수동 시험 순서

1. 데스크탑 그리퍼 프로그램에서 그리퍼를 연다.
2. 저속으로 물체 위 접근 자세로 이동한다.
3. 파지 위치로 천천히 내려간다.
4. 로봇을 완전히 정지한다.
5. 데스크탑 그리퍼 프로그램에서 낮은 힘으로 그리퍼를 닫는다.
6. 물체가 안정적으로 잡혔는지 확인한다.
7. 수직으로 조금 들어 올린다.
8. 영점을 잡았던 것과 같은 무게 측정 자세로 이동한다.
9. 로봇과 물체 흔들림이 멈춘 뒤 F/T 값을 기록한다.
10. 물체를 내려놓고 지지된 것을 확인한 뒤 데스크탑 프로그램에서 그리퍼를 연다.
11. 안전 자세로 복귀한다.

Fz만으로 `질량 = 힘/9.80665`를 계산하려면 센서 Z축과 중력 방향이 맞아야 한다.
다른 자세에서 정확한 무게가 필요하면 Fx/Fy/Fz와 로봇 자세를 이용한 중력 보상이 필요하다.

## 12. 센서 로그와 최종 필터

RB UI에서 센서 동작을 먼저 확인한 뒤, 노이즈 분석이 필요할 때만 PC에서 제어박스
Modbus TCP 데이터를 읽는다. 이 수집기는 로봇 이동 명령을 보내지 않는다.

```powershell
py rb5\capture_ft.py --host 10.0.2.7 --seconds 30 --hz 50
py rb5\filter_ft.py rb5\data\수집파일.csv
```

현재 필터 기준:

```text
EMA alpha:          0.1
안정 구간:          최근 1초
안정 판정:          질량 peak-to-peak 30 g 이하
Tare:               빈 그리퍼, 같은 측정 자세
```

현재 무부하 정지 로그 결과:

```text
raw Fz 등가 질량 표준편차: 약 13.4 g
최종 마지막 1초 표준편차: 2.61 g
마지막 1초 peak-to-peak:   9.39 g
안정 판정:                 yes
```

원본 CSV는 항상 보존하고 필터 결과로 덮어쓰지 않는다.

## 13. 재부팅이 필요한 경우

| 작업 | 재부팅 |
|---|---|
| `AIDIN_ID_SETTING()` 실행 후 M584 발생 | **제어박스 전체 재부팅 필수** |
| 외부 F/T 센서 종류 변경 후 UI가 요구함 | 요구 메시지에 따라 재부팅 |
| Tool/TCP 또는 payload 값만 수정 | 보통 불필요, 저장·적용 확인 |
| RB UI Disconnect/Connect | 재부팅 아님 |
| USB/단자 물리 배선 변경 | 전원을 끄고 변경한 뒤 다시 부팅 |

## 14. 문제 해결

### 14.1 RB UI가 연결되지 않음

1. `ping 10.0.2.7`을 확인한다.
2. PC Ethernet이 `10.0.2.10/24`인지 확인한다.
3. 랜선과 제어박스 부팅 상태를 확인한다.
4. RB UI가 LTS 8.4.4인지 확인한다.

### 14.2 AFT200 값이 없거나 모두 0임

1. 외부 F/T 센서가 `AIDIN AFT200`인지 확인한다.
2. 방향이 `Standard`인지 확인한다.
3. 전원을 끄고 CAN H/L, 5 V/GND를 확인한다.
4. 최초 등록이 안 됐다면 `AIDIN_ID_SETTING()`을 한 번 실행한다.
5. M584가 나오면 제어박스 전체를 재부팅한다.
6. 재연결·활성화 후 6축 값을 다시 확인한다.

### 14.3 Robotiq이 고정 빨간 LED이고 움직이지 않음

현재 실장비에서 실제로 발생한 미해결 증상이다. 다음 사실은 확인됐다.

- 그리퍼에 24 V가 공급된다.
- 과거 제어박스 USB 연결에서 RB UI reset/init 및 TCP 직접 명령에도 움직이지 않았다.
- DTECH 장치는 FTDI `0403:6001`, `FT232R USB UART` 계열로 확인됐다.
- 사진상 흰색→A+, 초록색→B- 배치는 맞다.

점검 순서:

1. DTECH USB가 Windows 데스크탑에 완전히 꽂혔는지 확인한다.
2. Windows 장치 관리자에 FTDI COM 포트가 생겼는지 확인한다.
3. COM 포트가 없으면 다른 USB 포트·연장선·FTDI 드라이버를 확인한다.
4. COM 포트가 있으면 `rb5_ui.py`와 Robotiq RUI 중 하나만 실행한다.
5. 전원을 끄고 Robotiq 24 V/GND와 흰색/초록색 단자 접촉을 확인한다.
6. 제어박스를 다시 켜 24 V를 공급한다.
7. `115200`, `8N1`, slave ID `9`로 연결한다.
8. reset → 약 1초 대기 → activate → 3~5초 대기 → 저속 open 순서로 한 번 시험한다.
9. 연결이 안 되면 Robotiq RUI `Auto Connect`, 이어서 `Recover Device`로 ID와 baud를 찾는다.
10. 계속 응답이 없으면 Robotiq 표준 `ACC-ADT-USB-RS485` 또는 검증된 변환기로 교차 시험한다.
11. 이후에도 실패하면 RS485 케이블 연속성 또는 그리퍼 통신 회로를 점검한다.

### 14.4 F/T 값은 안정인데 무게가 맞지 않음

- 영점 자세와 측정 자세가 같은지 확인한다.
- 물체나 그리퍼가 주변과 접촉하지 않는지 확인한다.
- 센서 케이블이 당겨지지 않는지 확인한다.
- 그리퍼·센서·어댑터 payload가 정확한지 확인한다.
- 같은 물체를 최소 5회 반복해 평균과 표준편차를 계산한다.

## 15. 정상 종료 순서

1. 잡은 물체를 안전한 곳에 내려놓는다.
2. 물체가 지지된 것을 확인하고 그리퍼를 연다.
3. 로봇을 안전 자세로 이동한다.
4. 데스크탑 그리퍼 프로그램을 닫아 COM 포트를 해제한다.
5. RB 프로그램 실행을 정지한다.
6. 로봇을 비활성화하고 RB UI 연결을 종료한다.
7. 제어박스 전원을 정상적으로 끈다.
8. 완전히 꺼진 뒤에만 USB나 단자 배선을 분리한다.

## 16. 현장용 한 줄 체크리스트

```text
전원 OFF 배선 확인
→ 제어박스 ON
→ RB UI 8.4.4 실행
→ 10.0.2.7 Connect
→ Control/Activate
→ 속도 5~10%
→ Tool/Payload 확인
→ AFT200 6축 확인
→ 데스크탑 COM 연결
→ Robotiq reset/activate/open/close
→ 같은 자세에서 F/T 0
→ 저속 파지·들기
→ 같은 자세에서 F/T 기록
→ 물체 내려놓기
→ 비활성화·Disconnect·전원 OFF
```

최초 AFT200 등록 때만:

```text
설정 → 일반 → 외부 F/T 센서 AIDIN AFT200
→ User Script Command: AIDIN_ID_SETTING()
→ 저장 → 테스트 1회
→ M584 확인
→ 제어박스 전체 재부팅
→ Connect/Activate
→ 6축 값 확인
```
